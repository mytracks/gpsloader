**First public pre-release.** myTracks Loader reads GPS loggers and converts logger files to GPX. It replaces the
logger functions of myTracks. It has seen little testing so far; please expect bugs.

**Requirements:** macOS 12 or later, Apple silicon or Intel (no Rosetta needed).

**Installation:** download `myTracks-Loader-0.1.0.zip`, unzip it and move `myTracks Loader` to the Applications
folder. The app is notarized by Apple. The user interface is available in English and German.

**Features**
- **Read devices:** over USB serial adapters, USB HID and Bluetooth, with erasing the memory where the device allows
  it. Supported: MTK loggers (iBlue 747, Qstarz and others), Holux M-241 and GPSport 245, SkyTraq Venus, Wintec
  WBT-100/200/201, G-Rays 2, WSG-1000, Locosys Navilink, Magellan Meridian/SporTrak/eXplorist, XAiOX iTrackU,
  i-GotU (erasing experimental) and the GNS 2000 over Bluetooth.
- **Convert files:** NMEA, GPX, IGC, FIT, TCX, Suunto SML, KML/KMZ, Columbus V-900 and iBlue CSV, memory images of
  SkyTraq, MTK and Holux, Wintec TES/TK1, Locosys SBP/SBN, Medion GoPal, Magellan and Alan Map500.
- **Device hints:** readable port names, hints on missing USB drivers and on devices that should be connected over
  USB instead of Bluetooth.
- **Support package:** "Help > Create Support Package…" collects system and device information in a ZIP file. It
  contains position data from the diagnostic captures; only share it with people you trust.
