# myTracks Loader (repository `gpsloader`)

Standalone macOS app that reads GPS loggers and converts logger files to GPX.
It replaces the logger functions of the app myTracks. Distributed by download, not through the App Store.
For users the app is called "myTracks Loader" (since 2026-11-19, change `rename-and-icon`); repository, target,
modules and bundle ID keep the name `gpsloader`. The icon is generated by `Scripts/make-app-icon.swift` (`App/AppIcon.icon`).

## Way of working

- Development is spec-driven with **OpenSpec** (`openspec/`). Before new features, create a change
  (`/opsx:propose`) instead of implementing directly.
- The project context, decisions and artifact rules in `openspec/config.yaml` are binding.
  Points marked there as "not yet confirmed" must be clarified with the developer before implementing them.
- Language (decided by the developer on 2026-11-19): everything in the repositories is English, including OpenSpec
  artifacts, README, docs, code, identifiers and comments. The conversation with the developer is in German. The app
  UI is localized in German and English. Archived changes from before 2026-11-19 stay in German as history.

## Important places

- `docs/legacy-analysis.md`: functional analysis of the old implementation. Covers drivers, protocols
  (BG728, GNS2000, i-GotU, NAL), gpsbabel versions and flows.
- `docs/legacy-device-catalog.md`: all devices of the current myTracks version with their driver assignment.
  i-GotU and WPL 1000 are not included, see the analysis.
- `docs/hardware-tests.md`: open hardware and user tests of the archived changes, with check criteria.
- `input/mytracks4mac/`: original myTracks code as a Git repository. **Read only**, never change it,
  never take it into the build. The folder is not versioned (`.gitignore`). The relevant places:
  - `DsTrackFramework/Source/Classes/GpsDriver/`: internal drivers BG728 and GNS2000.
  - `DsTrackFramework/Source/Classes/GPSBabel/GPSBabel.m`: driver choice and gpsbabel calls.
  - `myTracks/Source/Resources/gpslogger.plist`: device catalog.
  - `myTracks/Source/Resources/wsg2000/wsg2000.c`: description of the NAL format.
  - `myTracks/Source/Classes/Controller/MyTracksMainController.m`: import and erase flow (around lines 1800–2200).
  - `myTracks/Source/Classes/Controller/GpsLoggerWizard.m`: setup assistant and device detection.
  - Deleted code in the history:
    - i-GotU driver at `git show 3cbc727^:DsTrackFramework/Source/Classes/GpsDriver/IGotUGT800.m` (or `IGotU.m`).
    - gpsbabel 1.7.0 in commit `e0d1f18`.
  - `Import/Apps/GPSBabelFE170.app` and `Import/install-gpsbabel170.sh`: source of the gpsbabel 1.7.0 binary with Qt 5
    (only for black-box cross-checks).

## Technical guardrails (summary)

- Minimum macOS 12. The app is a universal binary without helper programs; it does not need Rosetta.
- Swift only (Swift 6 language mode, strict concurrency). No ObjC/C/C++ in the project.
- No gpsbabel in the app (decided on 2026-11-13, change `remove-gpsbabel`); all drivers are native.
  The gpsbabel 1.7.0 binary of the old app (commit `e0d1f18`) only serves black-box cross-checks: copy it to the
  scratchpad, never into the repository; run it as a process with an argument array, never through a shell.
- Native drivers still open: BG728 (package not decided yet) and WSG-2000 NAL (GPSLoggerKit, black-box). GNS2000 runs
  over IOBluetooth/RFCOMM (change `gns2000-driver`).
- Bluetooth loggers only through `/dev/cu.*`.
- No Python or Perl dependency, no `system()`/`popen()`.
- Protocol and parser logic in UI-independent Swift packages, testable without hardware.
- **Packages in their own repositories** (since 2026-11-19, change `split-repositories`), used in
  `Packages/GPSLoaderKit/Package.swift` by URL and `.upToNextMinor`, versions in `Packages/GPSLoaderKit/Package.resolved`:
  - [GPSLoggerKit](https://github.com/mytracks/GPSLoggerKit) (**MIT**, macOS 12+ and iOS/iPadOS 27+, clean-room;
    also used by myTracks Neo). Local checkout: `/Volumes/Dev/Projects/GPSLoggerKit`.
  - [GPSLoggerKitGPL](https://github.com/mytracks/GPSLoggerKitGPL) (**GPL-3.0-or-later**, macOS only, ports).
    Local checkout: `/Volumes/Dev/Projects/GPSLoggerKitGPL`.
  - Formats and device protocols change only with a change in the respective package repository; its `CLAUDE.md` and
    `openspec/config.yaml` apply there (clean-room or porting rules). **No GPL source code is read in this
    repository.**
  - A change works in exactly one repository: first a package change with a release, then a change here that raises
    the version and adds catalog, transport or UI. To develop against local package checkouts see README, "Packages".
- License of the app: GPL-3.0-or-later (`LICENSE`). Release builds need the source code address
  (`GPSLOADER_SOURCE_CODE_URL` in `project.yml`).
- The developer has no i-GotU and no Bluetooth loggers; users test those.
  The agent has no hardware.
